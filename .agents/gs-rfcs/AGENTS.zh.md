# AGENTS.md — GS-RFCs

[English](AGENTS.md) | 中文

GS-RFC 是 grill-me-sleek 的 RFC：持久的提案与决策记录，保存为什么、落败的备选方案、以及代码与 specs 承载不了的部分。完整契约见 [GS-RFC rules](README.zh.md)；仓库的[文档标准](../../specs/AGENTS.zh.md)治理所有文档。

**每份新记录都要先查重**（[scope](README.zh.md#when-to-write-one)）：该决策可能在这棵树里已有归属。

**绝不把一份记录改写成另一个决策**——用新的 GS-RFC 取代它并互相交叉链接（[lifecycle rules](README.zh.md#layout-and-naming)）。

`README.md` 与 `README.zh.md` 一起编辑；每份记录都以同样方式带一个 `.zh.md` 镜像（[文档标准](../../specs/AGENTS.zh.md)）。
